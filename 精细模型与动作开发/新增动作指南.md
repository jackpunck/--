# 新增动作指南

本目录采用「复用精细人体和骨架，为每个动作编写运动轨迹」的方式。当前已覆盖目录全部 25 个动作，包含 24 个往复动作和 `plank` 持续支撑。动作 ID 用来选择已有动画，当前没有自动生成任意动作的 AI 服务。

## 1. 先检查动作是否适合现有骨架

`atlas-rig.js` 中的 `createAtlasRig()` 创建 46 根控制骨骼，包含躯干、头部、双臂、双腿和手指。`pose(progress, exercise)` 接收运动幅度 `0…1` 和动作 ID。

原有三个动作在 `atlas-rig.js` 中计算关节位置，其余 22 个由 `motion-poses.js` 提供轨迹参数。新增动作需要定义轨迹，不能只向页面添加 ID；未知 ID 会恢复解剖姿态。新动作如需脊柱扭转、肩胛更细的运动或新器械，需要相应扩展骨架、蒙皮或器械代码。

## 2. 编写动作轨迹

优先在 `motion-poses.js` 配置运动；现有参数不足时再扩展 `atlas-rig.js`：

1. 为新动作增加关节位置与角度分支，保持上臂、前臂、大腿和小腿长度。
2. 处理接触地面或器械的支点；需要时使用逆运动学求肘、膝位置。
3. 设置手指开合和器械显示、位置与朝向。
4. 如增加控制骨骼，更新 `skinWeights()`、`bindGeometry()` 和相关检查。

模型采用 Y 向上、Z 向前的坐标约定，现有人体高约 3.15 场景单位。`rig.reset()` 恢复解剖观察姿态。

## 3. 添加动作资料和入口

- 在 `src.js` 的 `exercises` 中添加同名 ID，以及标题、器械、肌群、要领、常见错误、阶段说明和可靠参考链接。
- 在 `index.html` 的动作导航中增加 `data-exercise="新动作ID"` 按钮，并更新动作数量文案。动作较多时调整 `style.css` 的导航布局。
- 在 `exercise-catalog.js` 注册 ID，在 `motion-poses.js` 增加轨迹和阶段说明，并同步主应用目录与接口测试。
- `motion-timeline.js` 的 `sampleMotion()` 将播放周期映射为姿态进度和阶段，供骨架和颜色共同使用。等长动作配置 `isometric:true`。

## 4. 设置发力肌群

当前 13 个肌群 ID 见 `muscle-data.js`。在 `extended-activity-profiles.js` 为动作配置参与肌群、完整行程曲线、主辅角色和提示；归一化规则见 [动态颜色说明](动态颜色说明.md)。同一肌群可用于多个动作。

如需现有 13 个肌群以外的新高亮区域，可在 `atlas-model.js` 中根据 `item.name` 给现有命名网格增加角色映射，再增加对应标签锚点、锚点所绑定的骨骼以及 `src.js` 中的肌群说明。已有精细数据中包含这些结构，通常不必重新下载原始模型。不要把仍合并在普通 `muscle` 网格中的部位直接当作已可独立高亮的角色。

## 5. 验证动作

将新 ID 加入 `scripts/verify-rig.mjs` 的姿态循环、预览视图和高亮配置，按动作特点增加接触、长度和边界检查。

```sh
npm test
npm run build
npm start
```

在浏览器中观察整个周期的正、侧、背面，重点看肩、肘、髋、膝，检查肌肉穿插、握持、支撑点、标签跟随、播放暂停、阶段提示和窄屏布局。自动检查通过不能替代视觉检查和运动专业人员的动作审核。

## 可选：离线生成动作预览

安装 Python 及 numpy、Pillow、moderngl 后执行：

```sh
npm run preview:export
python scripts/render-model-preview.py .qa/rig
```

结果位于 `.qa/rig`。这里的 `.qa` 可以随时重新生成，不需要保留原演示目录中的缓存。

## 复用到其他项目

核心模块是 `atlas-model.js`、`atlas-rig.js` 和 `assets`。保持相对路径并安装本目录锁定的 Three.js 版本，使用支持 JSON 模块的构建工具：

```js
import {createAnatomyAtlas} from './atlas-model.js';

const human = createAnatomyAtlas({rigged: true});
scene.add(human.body);
human.rig.pose(0.5, 'curl');
human.setAppearance('neutral', [['biceps']], 'biceps', true);
```

独立移植时仍需要自行创建 Three.js 场景、相机、灯光和渲染循环。保留模型署名和 CC BY-SA 许可说明。
