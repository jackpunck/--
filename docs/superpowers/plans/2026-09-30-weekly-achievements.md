# 每周训练成就实施计划

**目标：** 训练页使用达成印记、完成文案和短暂纸屑；个人中心新增成就墙，静默保存每周成果。

**设计：** 两处复用同一个 SVG 印记，保留项目墨绿配色。成就墙显示累计达成周数、周日期范围和获得日期。每周以周一日期生成固定记录 ID，随账号同步。已获得成就不随日程重置或取消勾选删除。

## 实施步骤

- [x] 增加 `public/achievements.js` 和 `tests/achievements.test.mjs`：只在本周最后一项训练由未完成变为完成时返回成就记录；覆盖零训练、重复操作、移动和删除、跨年及复选框/实际记录两种完成方式。
- [x] 训练保存与成就使用同一批 RecordStore 写入；保留现有记录校验。页面刷新和同步不触发新奖励。
- [x] 新增复用的 `public/assets/weekly-achievement.svg`；训练页显示徽记和文案，详情关闭后播放一次 1.5 秒局部纸屑，减少动态效果偏好下不播放。
- [x] 导航和面包屑改名个人中心，新增成就墙标签与空状态；不自动打开或弹窗。
- [x] 更新静态资源缓存与语法检查，执行完整测试和隔离浏览器测试，验证桌面/手机、去重、刷新、重置保留及减少动态效果。
