# 默认繁忙日与节假日

采用已确认的 A 样式：顶部细线折叠行默认收起，摘要显示选中星期；展开显示七个星期按钮。繁忙日期统一浅绿色，移除来源图例和数量。

- [x] 测试并实现共享繁忙规则：手动日期覆盖、官方放假日空闲、每周默认规则，兼容已有 dates 数据。默认规则从保存当日起生效，保留此前规则以免重算历史循环位置。
- [x] 内置经官方通知核对的 2026 节假日，增加按年读取与缓存；未知年份明确标示，不能把调休上班日当放假日。
- [x] 循环安排与重排接收同一规则，避免只更新日历颜色；有界搜索避免全周繁忙时无限循环。服务端 AI 日历读写也使用同一规则。
- [x] 实现折叠 UI、星期多选、手动日期覆盖、取消不保存、保存后顺延，维持已完成训练日期。
- [x] 更新缓存版本，执行语法检查、全量测试和浏览器交互测试，检查手机尺寸及规则持久化。

## 数据与验证

- 2026 放假安排以国办发明电〔2025〕7号为依据：https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm 。内置该年数据；其他年份按需读取 https://github.com/NateScarlet/holiday-cn 并缓存于服务端和浏览器。未知年份显示数据暂不可用，继续采用每周规则和手动设置。
- `npm.cmd run check` 通过；`npm.cmd test` 共 177 项通过。
- 隔离 Edge 浏览器验证了首次折叠、星期多选、国庆放假例外、调休班标记、手动覆盖、统一样式、无数量、已有训练顺延、刷新恢复、取消、跨月、手机布局以及年度接口的不可用回退。
- 规则搜索有上限：没有足够空闲日期承接已有训练时显示提示，保存不会部分写入。
