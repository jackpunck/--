# 新增六种里程碑

用户已批准六种成就，直接实现。

**目标**：新增渐入佳境（10 次）、稳步前行（25 次）、百次积累（100 次）、一轮圆满（完整方案循环）、再次出发（间隔至少 14 天后回归，仅一次）、四季同行（累计 52 个达成周）。

**实现**：继续由服务端训练历史生成稳定 ID 的成就。累计次数和周数可使用已有确认历史补发。一轮圆满需要保留原循环快照及训练卡片的循环编号与位置，普通循环按包含休息日的原始位置，每周指定日期排期按训练日位置核验。再次出发在新卡片首次有效完成时记录前次训练依据及真实时间间隔，撤销、重新勾选旧卡片不制造回归记录。资料缺失的历史不猜测补发。新增徽章沿用蓝紫色圆形印记。

回归规则保留被撤销训练的确认时间，不能通过撤销中间记录扩充间隔。旧 v2 状态无法区分曾完成后撤销与从未完成；这类卡片不作为首次新训练触发回归，并在有不完整历史时建立迁移时间边界，之后有可信的新确认与完整 14 天间隔才获得回归成就。
