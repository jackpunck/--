# 成就系统与成就墙

用户已确认视觉稿与规则。本次直接实施并验证。

## 规则与边界

- 六种成就：首次训练、每周达成、累计 4/12/24 周、累计 50 次训练。
- 以训练卡片 ID 去重；有效完成要求非空有效动作全部勾选，或有效实际记录的全部动作有正组数与有效次数。未来训练不能提前完成。
- 正式记录由服务端维护，采用北京时间。周一零点后结算前周，页面当前周仅显示计划完成状态。
- 周结算按服务端截至周末已确认的训练状态，首次升级可核验现有历史；离线完成须同步后才能计入正式成就。
- 结算固定当周依据；之后补录或删除未完成训练不能补发那一周。撤销已完成训练会撤销依赖它的周成就及里程碑；重新完成可恢复原周已确认的依据。
- 删除或重置日历保留已确认历史；尚未同步的修改需先同步成功才能删除或重置，避免丢失完成与撤销记录。
- 旧周成就有明细的核验，没有明细的作为历史记录保留，标注历史来源；不能凭旧周成就捏造训练次数。
- 稳定获奖 ID、数据库事务、版本冲突和账号隔离共同避免重复发放。客户端不能直接写入正式成就。
- 保持现有蓝紫配色，一行四枚（手机自适应），每次获得的周成就独立展示，按最近周排列，卡片仅显示对应周日期范围；箭头、圆点分页，无页码。详情展示条件与获得历史，下方一条下一目标进度。
