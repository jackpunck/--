# 每日寄语

用户已确认精选文案库方案及预览：保留原卡片的字号、字重、行距、间距、颜色、星芒图标和下方十二根动态柱条。顶部仅显示“今日寄语”，不显示日期、不增加操作按钮。每天替换短标题和两行正文。

使用 60 组原创简短文案，覆盖坚持、休息、饮食、成长和自我接纳。标题最多 9 个字符，每行正文最多 12 个字符，沿用现有卡片尺寸。

按浏览器当地日历日期选择文案，同一天刷新或切换页面时一致，跨日按顺序选择下一组，60 天后循环。使用当地年月日转换为 UTC 日序，避免夏令时导致日序偏差。以 2026-10-02 为起点，首组采用预览中的“每一步，都算数。”。

首屏渲染立即填入文案，复用现有 30 秒轮询和页面恢复可见事件检查跨日；仅更新文案节点，保留柱条节点及 CSS 动画。内容随静态资源离线缓存，不调用模型或新增接口。

验证覆盖同日一致、连续日期变化、跨年、闰日、夏令时，以及整个文案周期内不重复。确认 CSS 未改动，并执行现有语法检查和测试套件。
