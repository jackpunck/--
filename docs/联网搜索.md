# 用户模型的联网能力

默认开启 Exa MCP 免密钥搜索：配置好对话模型后即可按需联网，无须再注册搜索服务或填写搜索密钥。在「个人中心 → AI 服务 → 联网搜索」可直接测试连接、关闭联网，或切换到 Tavily / Brave Search 使用自己的搜索密钥和额度。免费公共服务仍受频率与可用性限制，失败时明确提示，不会自动改用付费服务。

未保存过搜索设置的账号采用上述默认值；已有账号主动保存的服务选择和关闭状态继续保留。默认免费模式隐藏密钥输入框，切换到可选付费 API 服务时才显示。测试按钮执行一次公开关键词搜索。

搜索由应用提供，不复用或向搜索引擎发送模型供应商密钥。当前支持已有的 OpenAI 兼容、Anthropic、Gemini 三种协议。具体模型及供应商接口仍需支持工具调用；接口明确拒绝工具时，本轮回退为普通回答并提示没有联网，不能将此情况解释为已获得最新资料。

## 使用行为

- 对话、规划建议、餐食识别请求均可按需调用 `web_search`、`read_web_page`。普通问答不强制搜索；用户明确要求联网、最新信息或外部核实时，提示模型先检索再作答。
- 搜索返回最多 5 个来源及摘要，可选最近一天、一周、一月、一年的时间范围。摘要不等于网页全文；模型可继续读取公开网页以核对细节。
- Exa 的时间范围通过搜索要求传递，并非严格日期过滤；结果中明确提示核对来源发布日期。Tavily 与 Brave 使用各自 API 的时间过滤参数。
- 对话展示搜索状态、查询时间和可点击来源，刷新后可从历史对话再次查看。历史中保留来源链接，不保留完整网页文本或搜索摘要，避免后续对话反复携带大段旧资料。
- 网页读取仅支持公开 HTML/文本，不登录，不执行脚本，不解析 PDF。最多读取 8000 字符并标明截断；网站拒绝访问、超时或内容类型不支持时返回具体状态，不声称已核实。
- 自动动作点评继续以用户视频与骨架证据为依据，不将联网内容当作用户动作事实。
- 关闭联网设置后，新请求不再提供联网工具；已经开始的对话请求需点击「停止生成」。调用 API 的客户端也可通过 `context.webSearch=false` 对单次请求关闭联网。

## 服务端与数据边界

`server/web-search.mjs` 提供 Exa MCP、Tavily、Brave 三个适配器、网页提取、预算限制与配置存储。Exa 请求固定公开端点 `https://mcp.exa.ai/mcp`，不附加认证头，调用 `web_search_exa`，兼容 JSON 与 SSE 响应；协议错误和工具错误不会被解释成成功的空结果。设置按账号保存在 `web_search_settings`，可选服务的密钥使用现有 AES-GCM 加密；GET、个人导出、模型上下文均不返回密钥。更换搜索服务不沿用原密钥，切回免费模式会清除原密钥；账户删除级联清理设置。保存带版本号，冲突返回 409，不覆盖其他页面的新配置。

模型只应发送必要的公开搜索词，不能把健康档案、餐食记录、附件原文、完整对话或密钥放入查询。模型 API 密钥与搜索服务密钥有独立检查，搜索输出中的搜索密钥回显也会被清除。搜索服务只能请求固定官方端点，不能由模型指定搜索 API 地址。

读取网页时，每次跳转均重新检查 URL 和全部 DNS 解析结果，并将实际连接固定到已检查的公开地址。即使部署允许连接本机模型，也禁止网页工具读取本机、内网或云元数据地址。最多 3 次跳转、512 KB 响应；每次联网超时 12 秒，每轮最多 3 次搜索与 3 次网页读取，并计入现有上下文工具预算。停止对话会取消正在进行的联网请求。

网页与搜索摘要均标记为不可信资料；其中的文字不能授权修改用户记录、读取敏感资料或改变任务。来源优先采用官方与原始资料，回答须区分发布日期、查询时间与不确定性。检索失败或没有结果不是事实不存在的证明。

## 接口

- `GET /api/web-search`：当前账号的服务、开关、是否有密钥、版本号。
- `PUT /api/web-search`：`{provider:"exa-mcp"|"tavily"|"brave", enabled:boolean, version:number, apiKey?:string, clearKey?:boolean}`。免费模式无需密钥。付费模式留空密钥保留同服务原密钥；更换付费服务需要新密钥，清除密钥时须同时关闭联网。
- `POST /api/web-search/test`：用已保存配置执行一次公开示例搜索，返回结构化状态和来源。需登录，与模型请求共用账号并发限制。
- `POST /api/ai`：启用后自动将联网工具挂载到配置的模型；非流式结构化任务只返回最后一轮模型文本，保留原有营养建议 JSON 检查与修复流程。

## 验证与来源

`npm run qa:web-search` 使用临时账户和模拟模型/搜索服务，验证配置保存、测试连接、模型检索、来源持久化、搜索失败、关闭行为及手机布局，不消费真实搜索额度。`tests/web-search.test.mjs` 覆盖三种模型协议、搜索适配器、真实 HTTP 接入、加密与账号隔离、版本冲突、内网及跳转限制、超时/取消、响应长度与来源渲染。

免密钥方案参考 [Cherry Studio 免费联网说明](https://cherryai.com/docs/en/pre-basic/websearch/free-search/)、[Exa 官方 MCP 说明](https://exa.ai/mcp) 与 [官方 MCP 仓库](https://github.com/exa-labs/exa-mcp-server)。已在真实公共端点核对工具协议，并通过应用适配器验证免密钥搜索返回 WHO 官方网页来源；公开网页读取也已实测。

可选付费协议参考 [Tavily 官方 Search API 说明](https://help.tavily.com/articles/4840311948-tavily-search-api)、[Tavily 官方 SDK](https://github.com/tavily-ai/tavily-python/blob/master/tavily/tavily.py) 和 [Brave 官方 Web Search 文档](https://api-dashboard.search.brave.com/app/documentation/web-search/codes)。这两个供应商使用官方响应结构模拟验证，真实连接需用户保存其有效密钥后测试。
