# 动作封面素材来源

本文件登记知识库动作卡片真人封面的来源与授权，格式参照 `精细模型与动作开发/assets/ANATOMY-SOURCE.md`。图片文件存放在 `public/assets/exercises/`，命名与规格见该目录的 `README.md`。

**当前状态：25/25 个动作已收录真人封面（2026-09-29），全部来自 free-exercise-db。**

获取方式：`node scripts/fetch-exercise-covers.mjs`（已存在的不覆盖，`--force` 重新下载，`--dry-run` 只打印对照表）。下载后运行 `npm run covers` 生成清单。

## 采用来源

**[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db)** — 开放动作数据集，876 个动作，每个动作两帧真人实拍照片（`0.jpg` 起始位、`1.jpg` 发力/结束位）。

- 授权依据：仓库 [LICENSE.md](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md) 为 **Unlicense（公共领域）**，可用于任何目的、无需署名。数据集原始出处为 [Ollie Jennings 的 exercises.json](https://github.com/wrkout/exercises.json)。
- 图片地址：`https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/<条目名>/1.jpg`
- 原始规格：850×567（正好 3:2），33.6–98 KB/张，合计 1.49 MB。**与卡片规格一致，未做裁切、重压或调色处理。**
- 本项目取每个动作的 `1.jpg`（发力/结束帧），因为起始帧画面张力弱、作为封面不够清楚。

### 与中文动作名的差异

数据集只有英文条目，以下四条的器械或动作细节与中文卡片不完全一致，属于最接近的可用条目：

| 动作 id | 中文卡片 | 采用条目 | 差异 |
| --- | --- | --- | --- |
| rdl | 哑铃罗马尼亚硬拉 | Stiff-Legged_Dumbbell_Deadlift | 数据集里的 `Romanian_Deadlift` 是杠铃版，为匹配"哑铃"选了直腿硬拉条目 |
| lunge | 反向箭步蹲 | Dumbbell_Rear_Lunge | 中文标注"徒手或哑铃"，采用哑铃后撤箭步 |
| goblet-squat | 高脚杯深蹲 | Goblet_Squat | 数据集该条目的 `equipment` 字段写的是 kettlebells（壶铃） |
| calf-raise | 站姿提踵 | Standing_Dumbbell_Calf_Raise | 数据集里的 `Standing_Calf_Raises` 是器械版，为匹配"徒手或哑铃"选了哑铃版 |

### 已知局限

- **模特不统一**：数据集由多人拍摄，25 张封面里会出现不同体型、不同着装的模特，风格一致性弱于自拍或用同一角色描述生成的 AI 图。
- **影调偏重**：多数照片是深色健身房环境（红墙、黑地垫），与应用的浅绿/米白配色反差较大；卡片下方白色信息区提供了分隔，如需更贴合可统一降低饱和度或加浅色叠加层。
- **构图不齐**：部分条目的动作主体偏小或偏在一侧（如 `curl`、`pushup`）。`object-fit:cover` 会居中裁切，不接受这种构图时可自行替换单张图片，替换后运行 `npm run covers` 即可。
- **肖像权说明**：数据集以 Unlicense 发布其仓库内容，但未附带模特授权书（model release）说明。用于参赛演示没有问题；若后续商业化发布，建议替换为自有拍摄素材。

## 未采用的来源

以下类型素材无授权依据，本项目不使用，记录在此以免后续误引入：

- 百度图片、必应图片、小红书、抖音、B 站、微博等平台上的图片与视频截图。
- Keep、乐刻、训记等商业 App 的界面截图或课程封面。
- 未标注许可的健身房官网、博主博客配图。
