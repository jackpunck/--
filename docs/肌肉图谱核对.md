# 肌肉图谱名称与位置核对

核对日期：2026-09-29。

**斜方肌补充更正：**上一轮检查了整体肌群，但未识别导入数据内部的斜方肌上、下部分名称互换。后续专项核对已确认中部正确、左右两侧上部与下部均标反，并完成修复。整体入口核对不能代替所有内部分区的逐项验证。

## 范围与结论

- 逐项查看知识大全的41个入口：13个肌群、28个左侧独立结构。检查高亮范围、所在部位、默认视角和显示名称。
- 对模型肌肉集合中的433个可选择结构检查中文名称、分部名称及左右侧坐标；该集合也包含肌腱、腱膜和支持带，名称中保留其组织类型。
- 对全部700个结构检查三角面到源结构的映射；独立结构高亮使用源网格对应的三角面，不使用另画的近似区域。
- 未发现这些入口的网格被接到错误身体部位，也未发现左右侧标签与坐标反置。模型自身的左侧在正面观察时位于屏幕右边，背面观察时位于屏幕左边。

以上结论针对应用映射、名称及展示。源模型细小附着点的医学精度没有逐点重新测量。

## 发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| `Coracobrachialis`因包含`brachialis`被误译成肱肌 | 改为完整词匹配，喙肱肌与肱肌分开；长词优先，防止半棘肌与棘肌混淆 |
| 胸最长肌、腰髂肋肌等丢失具体分区；部分肌头、肌腹和深浅分部重名 | 补齐分区与分部，433个结构的中文显示名不再重复 |
| 部分前臂、手足、头颈结构只有英文 | 补齐中文名，手的指与足的趾、肌肉与肌腱明确区分；详情保留英文源结构名 |
| 腹部核心高亮被表层网格挡住，看起来没有选中 | 图谱肌群与独立结构都采用明确标注的透视高亮，显示原有深层网格 |
| 点击透视高亮的深层肌肉，可能命中覆盖它的表层肌肉 | 优先拾取正在显示的高亮几何；高亮范围之外继续拾取表面结构 |
| 三角肌后束、冈上肌、冈下肌、大圆肌和小圆肌默认从前侧观察 | 改为背面观察；三角肌前束、肩胛下肌及胫骨前肌默认正面观察 |

## 斜方肌三个分部专项核对

正确对应关系为上部（descending）、中部（transverse）、下部（ascending）。名称中的上行或下行描述纤维走向，不是身体位置高低。位置与分部依据：[解剖教学资料](https://www.kenhub.com/en/library/anatomy/trapezius-muscle)、[Elsevier肩胛区章节](https://booksite.elsevier.com/samplechapters/9780323037440/9780323037440.pdf)。

发现：导入资产标为`Ascending part`的几何实际位于颈后及肩顶部，而`Descending part`的几何位于背部下方。两侧均相同；`Transverse part`正确。

修复：交换四个错误的结构标识，保留原始`sourceName`。没有更改几何顶点、三角面、压缩数据、左右侧或蒙皮。压缩几何数据字符串的SHA-256仍为`877816bcc992c00ceceb940304a51ee6e3554b1faf9fa3ae9efe7fef5a0e7b9c`。更正规则保存在`assets/anatomy-name-corrections.json`，导出器和绑定区域生成器已使用这些规则，避免重建时恢复旧错误。

新增上、中、下部三个独立入口（当前图谱44项）；对话里的上束、中束、下束分别指向对应网格。独立入口默认展示左侧；模型表面点击仍可识别右侧结构。

验证：新增测试先在旧资产上失败（上部网格实际位于下方），修正后通过。两侧几何中心高度均为上部2.735、中部2.615、下部2.430（模型坐标，仅用于空间顺序检查）。模型全套测试通过，主应用126项测试通过。
