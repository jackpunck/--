# 训练日程与 AI 操作

## 按日期展示训练

「训练计划」按周显示七个日期，每天一格，当天的训练任务放在对应日期下。页面提供上周、下周、本周和日期选择；手机可在表格内横向滚动。

- 点击「添加训练」或日期格中的加号，选择训练内容、日期，填写名称和备注。
- 拖动未完成训练到另一日期，或点击「调整」修改日期。同一任务保留原记录 ID 和动作快照，不会复制成两条。
- 同一天可以安排多项训练，卡片按天集中显示。
- 打开卡片可记录实际组数、次数、重量和体感。已完成训练保留日期；实际训练数据仍可修订。
- 训练循环和动作列表在表格下方展开查看。

日常任务和上午、下午、晚上分区已取消。新增任务只需日期，不需要开始、结束时间。旧版日常任务数据继续保存在原账户中，但不显示、不参与排期和营养判断。

## 饮食页自动判断日类型

饮食页日期旁显示自动计算的「训练日」或「休息日」，无需手选：

- 所选日期至少有一项有效训练任务：训练日。
- 没有训练任务：休息日。
- 已完成训练仍使该日期属于训练日；已删除任务不计入。
- 同日多项训练，移走或删除最后一项后才变成休息日。

新增、拖动改期、编辑日期、删除和 AI 变更都会重新计算原日期和目标日期的日类型及营养目标。刷新或同步另一设备的修改后，页面也读取同一份训练数据。旧的手动日类型记录不再覆盖结果。

## AI 按日期安排

例如：

- 「创建并保存一个居家三分化训练计划，安排接下来七天。」
- 「把周三的腿部训练移到周六。」
- 「修改计划，把哑铃深蹲改为两组。」
- 「删除当前训练计划。」

AI 先读取当前账号的真实训练日程和计划版本，再按训练循环和指定日期范围保存任务，默认从今天起七天。循环中的休息日不新增训练；已有无关训练和完成记录继续保留。更新计划会调整范围内未来未完成的关联训练，删除计划会移除未来未完成的关联训练。

## 今日饮食

在对话中明确要求记录、修改或删除今日饮食时，AI 可以直接执行并更新营养合计。例如：

- 「记录今天午餐：熟米饭 200 克、去皮熟鸡胸肉 150 克，请估算营养并保存。」
- 「刚才午餐的米饭实际吃了 100 克，帮我修改记录。」
- 「删除今天刚才重复记的那顿午餐。」

工具会先读取餐食 ID 和版本，再更新相应记录。食物营养字段为每 100 克数值，营养总量根据实际克数计算。只是询问食谱或估算而未要求记账时，继续作为建议；餐食照片编辑器仍保留原来的确认入账流程。

## 保存、冲突与历史

- 新训练使用 `calendar-task` 记录；旧 `schedule` 训练按原 ID、实际 `data.date` 显示，不批量改写历史。旧时刻字段不影响按天展示。
- 训练保存 `daySnapshot` 与 `planVersion`，之后更换固定计划不会使已完成记录显示为新动作。
- 训练、计划和饮食继续通过账号隔离、离线队列及版本冲突机制同步。AI 操作需要联网，发送前先同步本地修改。
- 工具操作在事务中检查记录版本。同一次回答的重试或重新生成使用原请求 ID，避免重复记餐或重复创建训练。
- 停止回答不撤销已经保存的操作。以服务器回执和页面实际记录为准。
