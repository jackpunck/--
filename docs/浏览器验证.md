## AI 测试的边界

测试服务通过 `fetchImpl` 注入固定的 Chat Completions 响应，**没有调用真实商业模型，也没有验证餐食识别准确率或模型建议质量**。照片使用两张小型 PNG 测试文件，实际上传、保存、附件引用、餐前餐后修订和确认入账流程均走应用的真实接口。手机检查为浏览器窗口模拟，未验证实体手机摄像头或移动 GPU 性能。

离线重载验证运行在浏览器视为可信来源的 `127.0.0.1` 上。手机访问局域网 HTTP 时可使用普通网页，但 Service Worker 离线重载需要 HTTPS；不能把本次本机结果视为已覆盖局域网 HTTP 的离线安装。

